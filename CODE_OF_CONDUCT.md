# Code of conduct

Stacks follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and patient. Many contributors are students or new to open source.
- Criticise code and ideas, not people.
- No harassment, insults, or discriminatory language, in issues, pull requests or anywhere else connected to the project.
- Assume good intent, and say so plainly when something is not working for you.

## Reporting

If someone's behaviour breaks these rules, report it privately to the maintainer through the repository's **Security** tab ("Report a vulnerability" opens a private thread; say that it is a conduct report). Do not post the report in a public issue.

Reports are read by the maintainer, kept confidential, and answered within 7 days. The maintainer may edit or remove comments, close threads, or block an account from the project.
